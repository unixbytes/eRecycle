# EcoRecycle

Electronic waste recycling management system built with Flask, SQLAlchemy, and WTForms.

Features
- Client pickup request form
- Admin dashboard and request management
- Request tracking
- QR code labels
- Email confirmations
- GPS-based address autofill

Tech Stack
- Python
- Flask
- SQLAlchemy
- WTForms
- SQLite

Local Development
1. Install dependencies:
   ```
   uv sync
   ```
2. Run the app:
   ```
   uv run python run.py
   ```
3. Open:
   - http://127.0.0.1:5000/
   - http://10.10.10.6:5001/
